# Indie Games on Steam

Exploratory analysis of indie games on Steam, followed by an investigation of how games that disclose AI-generated content compare to those that don't.

**Status:** in progress (part 1: data cleaning and exploration).

## Data
This project uses the [Steam Games Dataset](https://www.kaggle.com/datasets/fronkongames/steam-games-dataset) by FronkonGames.
The data is not included in this repository. To run the notebook, download `games.csv` and place it in a `data/` folder.
